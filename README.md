# English_word · 주제별 영어 단어장

공부하고 싶은 주제를 골라, 서로 관련 있는 영어 단어를 함께 익히는 단어장입니다. 처음 보는 표현은 한국어 뜻과 나란히 읽고, 익숙해지면 영어를 가린 채 스스로 떠올려 보세요.

[![영어 단어장 열기](./assets/open-study.svg)](https://kookjd7759.github.io/English_word/study/?v=0e854b0)

## 이렇게 공부해 보세요

1. **주제 고르기** — 파일 목록에서 오늘 익힐 주제를 선택하세요. 범위를 좁히고 싶으면 소주제를 고르거나 한국어·영어로 단어를 검색하세요.
2. **뜻을 보고 떠올리기** — 목록에서 **영어 가리기**를 누르고 한국어 뜻을 읽어 보세요. 기억이 흐릿한 단어만 **정답 보기**로 확인할 수 있습니다.
3. **카드로 복습하기** — **카드로 복습**을 누르면 지금 보고 있는 범위에서 한 장씩 연습할 수 있습니다. 카드를 누르거나 스페이스바로 뒤집고, 좌우 방향키로 앞뒤 카드를 넘기세요.

## 단어장에 주제 더하기

[words 폴더](./words/)의 Markdown 파일 하나가 주제 하나입니다. 기존 파일에 단어를 보태거나 새 파일로 주제를 추가한 뒤 main 브랜치에 푸시하면, 배포가 끝난 후 단어 목록과 복습 카드에 반영됩니다.
